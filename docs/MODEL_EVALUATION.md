# Model status and evaluation gate

No trained classifier, evaluation corpus or calibration results are bundled. The default adapter always abstains with a null probability. Descriptive thresholds are not classification thresholds. Tests use human-like, model-like, mixed, short, quoted and learner prose only to verify software behavior, never to establish detection performance or authorship ground truth.

`backend.analysis.Detector` defines the inference boundary. Before an adapter can be enabled, require a versioned model artifact and checksum, tokenizer, model license, inference code, supported languages/genres/lengths, dataset provenance and consent, a model card, held-out independent evaluation and an explicit calibration artifact. Do not simply register an unvalidated model or use an LLM-generated likelihood. The application currently intentionally exposes no configuration switch that can bypass this gate.

## Evaluation utility

Run `.venv/bin/python -m backend.evaluate path/to/predictions.jsonl` against real independently generated predictions. Each record requires `text`, `split` (train/validation/test), `label` (0/1), `probability` (finite 0..1), and `group` (writer/domain subgroup). Never place private corpora under version control. The utility rejects cross-split exact and near-duplicate normalized texts (SequenceMatcher > .9), then computes held-out precision, recall, F1, FPR, FNR, ROC-AUC, average precision, Brier score and 10-bin calibration error, including length and group breakdowns. The pairwise duplicate check is intended for modest local corpora; use indexed deduplication at scale. Similarity screening cannot establish freedom from semantic or provenance leakage.

Training, calibration/threshold selection and final testing must be separate. Group splits by source author, prompt, topic and generator family; include time-held-out generators, non-native writers, different genres, lengths, human edits of AI and AI edits of human text. Define mixed-authorship labels and abstention policy explicitly. Record sample counts and uncertainty intervals, evaluate false positives by writer group, OOD and unsupported language behavior, and independently reproduce results. Default reporting threshold .5 in the utility is not a validated product decision threshold. Tune abstention only on validation evidence, freeze it, then evaluate test coverage and error rates. Calibration metrics alone do not establish calibration. This repository supplies no accuracy claim.
